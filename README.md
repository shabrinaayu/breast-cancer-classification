# Breast Cancer Classification Using Decision Tree

## Project Overview
This project applies a Decision Tree classification algorithm to the Breast Cancer Wisconsin (Diagnostic) dataset to classify tumors as benign or malignant.

## Dataset
- **Source:** UCI Machine Learning Repository
- **Dataset:** Breast Cancer Wisconsin (Diagnostic)
- **Number of observations:** 569
- **Number of features:** 30

## Methodology
1. Data loading and exploration
2. Data quality checking
3. Train-test split (80:20)
4. Decision Tree model training
5. Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix
6. Feature importance analysis

## Model Performance
- **Algorithm:** Decision Tree Classifier
- **Max depth:** 4
- **Accuracy:** 91.23%

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Google Colab

## Disclaimer
This project is for educational purposes only and is not intended to replace professional medical diagnosis.
